# Nexora Corp. — o login impossível

Site de humor que imita o login de uma empresa fictícia. Os botões fogem, se juntam, explodem e o site fica mais caótico a cada tentativa. Nada é enviado ou salvo; tudo recomeça ao recarregar.

## Como ganhar
Faça 7+ tentativas, preencha tudo (e-mails e senhas iguais), escolha um cargo, aceite os termos, resolva o captcha (Segunda-feira, Café frio e Reunião às 18h) e segure o botão final por 5 segundos.

## Rodar no computador
1. Instale o [Bun](https://bun.sh) (ou Node 20+).
2. Na pasta do projeto: `bun install`
3. `bun run dev` e abra http://localhost:8080

## Publicar
- No Lovable: clique em **Publish**.
- Ou gere os arquivos com `bun run build` e publique em um serviço compatível (ex.: Cloudflare).
